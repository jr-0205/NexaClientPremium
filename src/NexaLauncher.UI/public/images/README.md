# NEXA UI Images

Esta carpeta contiene las imágenes visuales reemplazables de la experiencia NEXA.

## Fondo reservado

- `image-1.png` — fondo principal pendiente para el launcher y referencia visual para NEXA In-Game.

Mientras `image-1.png` no exista, la interfaz debe usar su fondo oscuro nativo y no mostrar imágenes rotas.

Cuando se entregue la imagen definitiva, reemplazar/añadir únicamente `image-1.png`; no cambiar el nombre ni la ruta. El pipeline de NEXA In-Game deberá sincronizar esta imagen a su recurso empaquetado correspondiente para mantener la misma identidad visual dentro y fuera del juego.
