# Contexto temporal

Carpeta temporal para referencias visuales y funcionales durante el rediseño de NEXA Client y NEXA In-Game.

Puedes colocar aquí:

- capturas del menú de Lunar Client;
- iconos de referencia;
- ejemplos de distribución de módulos;
- ejemplos de HUD/editor de posiciones;
- referencias de menús, tablas, toggles y navegación.

## Uso

El contenido de esta carpeta se utilizará como referencia de UX/UI y comportamiento para diseñar una implementación original de NEXA.

No debe tratarse como carpeta de assets de producción. Los recursos definitivos de NEXA deben vivir en sus carpetas oficiales (`src/NexaLauncher.UI/public/...`, recursos de `ingame/...`, etc.) y mantener identidad propia.

Esta carpeta puede eliminarse cuando termine la fase de diseño.
